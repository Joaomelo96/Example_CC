# Example_CC

Projeto de exemplo criado durante o **Curso Udemy de Claude Code (2026)**.

O objetivo deste repositório é servir de ambiente de prática para explorar as funcionalidades do [Claude Code](https://claude.com/claude-code), o assistente de programação da Anthropic que corre no terminal.

## Objetivos

- Experimentar o fluxo de trabalho com o Claude Code no terminal
- Gerar e editar ficheiros com a ajuda do assistente
- Praticar a integração com Git e GitHub (commits, push, pull requests)

## Requisitos

- [Git](https://git-scm.com/)
- [Claude Code](https://docs.claude.com/en/docs/claude-code/overview) instalado e autenticado

## Como começar

```bash
git clone https://github.com/Joaomelo96/Example_CC.git
cd Example_CC
claude
```
